# Sistema de Solicitudes de Biblioteca

Proyecto desarrollado en C# mediante Visual Studio.

## Descripción
Sistema que permite administrar solicitudes de una biblioteca utilizando listas enlazadas.

## Funcionalidades
- Registrar solicitudes.
- Buscar solicitudes por código o nombre.
- Modificar y eliminar solicitudes.
- Mostrar solicitudes pendientes.
- Consultar estadísticas.
- Guardar y recuperar datos mediante archivos TXT.

## Estructura del proyecto
- `Program.cs`: Inicio del programa.
- `NodoSolicitud.cs`: Almacena los datos de cada solicitud.
- `GestorBiblioteca.cs`: Gestiona las operaciones del sistema.

## Control de versiones
El proyecto utiliza Git y GitHub para registrar los avances de implementación.
